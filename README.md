# iTab Quest — art assets

Approved art for the iTab Quest web game, and the Gemini downloads it was produced from.

| Path | What |
|---|---|
| `itab_quest_approved_assets_v1/` | The production assets: `backgrounds/`, `characters/`, `branding/`. See its `ASSET_VERIFICATION.txt` for the status of every file. |
| everything else at the top level | Original Gemini downloads, kept unchanged for reference. |

The art direction is locked. Changes to these images need Michael's approval. Fretboards,
tab lines, labels and UI text are drawn in code, not baked into the images.

`itab_quest_approved_assets_v1.zip` is built from the folder and is not committed.
