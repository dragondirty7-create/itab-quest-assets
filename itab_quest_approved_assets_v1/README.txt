iTab Quest - Approved Assets v1

These are the locked, approved v1 art assets for iTab Quest.
Do not redesign, redraw, recolor or restyle them without Michael's approval.

backgrounds/   16:9 game backgrounds, 1920x1080 PNG (no transparency)
characters/    transparent production character art (PNG with real alpha)
branding/      transparent production logos (PNG with real alpha)
ui/            character feedback poses (correct, try again, hint). Their transparency
               still needs cleanup; see ASSET_VERIFICATION.txt.

Interactive fretboards, tab lines, labels and all UI text are drawn in code.
They are not baked into these images and should not be added to them.

Status and details for every file: ASSET_VERIFICATION.txt
